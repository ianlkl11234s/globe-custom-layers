How do I turn this into a prompt for an AI coding agent?

The more specific the instruction, the better. Suggested template:

"Place a [size, e.g. 300m tall] [color, hex or description] [effect name] at [lng/lat or place name], with [behavior, e.g. pulsing, rotating, gradient direction]."

Example: "Place a 200m tall cyan light beam at Taipei 101, wide at the base and narrow at the top, pulsing once every 2 seconds."

Parameters worth being explicit about:

  • blending: Additive (bright, stacks with what's behind it) / Normal (plain transparency)
  • opacity: 0-1
  • geometry: Cylinder / Cone / Sphere / Torus / Plane / Custom
  • shader: vertex displacement (a "skirt" swaying in place) / fragment color (flowing gradient)
  • particles: count, lifetime, initial velocity
  • animation: sine pulse / linear rotation / expanding ripple

Why mercator, not globe?

Every effect here places itself with a single absolute MercatorCoordinate, computed once in onAdd(). That's the "unless your geometry moves" shortcut this repo's globe-hugging recipe explicitly calls out as mercator-only — correct at any zoom under flat mercator, wrong the moment the base map switches to globe projection, because nothing here reads Mapbox's globe projection / projectionToMercatorMatrix / projectionToMercatorTransition render arguments.

If you want these effects to hug the sphere, don't rewrite all 68 — apply ../../docs/01-hugging-the-globe/mapbox.md (recipe 1.1) to core/layer.js once, the same way examples/01-points-on-globe does it.
